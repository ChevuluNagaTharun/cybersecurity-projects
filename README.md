# CyberScan - Advanced Port Scanner

CyberScan is a modern cybersecurity-focused port scanner built using Python. This project demonstrates network scanning, cybersecurity concepts, socket programming, and modern UI design for ethical hacking and security analysis.

---

## Features

- Fast TCP Port Scanning
- Modern Cybersecurity UI
- Real-time Scan Results
- Beginner Friendly Interface
- Network Security Concepts
- Lightweight and Efficient

---

## Technologies Used

- Python
- Socket Programming
- Tkinter GUI
- Networking Concepts
- Cybersecurity Fundamentals

---

## Project Goal

The goal of this project is to build practical cybersecurity tools while improving knowledge in:

- Ethical Hacking
- Network Analysis
- Security Tool Development
- Python Automation
- Cybersecurity Engineering
